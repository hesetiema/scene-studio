同一批属性，两个 viewer宣传页 · 不参与 e2e

左：<model-viewer>（官方 CDN） · 右：<scene-editor>（本仓库）。 上方开关会同时写给两个元素——除了前缀不同，属性名是同一套。

正在从 CDN 加载 <model-viewer>…（离线或被拦截时右侧仍可用）

model-viewer src · autoplay · auto-rotate · shadow-intensity · exposure
scene-editor src · autoplay · auto-rotate · shadow-intensity · exposure · variant-name

差异（诚实版）

  • poster / reveal / progress-bar / hotspot 插槽： 已实现；seamless-poster 也已实现——首帧渲染完成后海报以 300ms 淡出， 不再是一帧切换的闪变。interaction-prompt（3s 无操作后出现的转动提示） 与 interaction-prompt-threshold 同样对齐。
  • ar / ar-modes / quick-look / xr-environment：不做（无 XR）。
  • variant-name（KHR_materials_variants）：已实现——元素 variant-name / availableVariants，运行时 variants / setVariant()。three r186 不解析该扩展，这里直接读 glTF JSON 的 mappings，并用 parser.associations 把每个 primitive 对回 Mesh。 本页的 Fox 不含变体，故此项无法在此对照。
  • 接触阴影已同源：不再是方向光投影，而是移植 model-viewer Shadow 的算法—— 正交相机贴在**地面上**朝上，用深度材质把「离地高度」写成 alpha，两遍可分离模糊后 贴在透明面上。所以阴影贴住足印并向上淡出，而不是从脚下拖出去。 shadow-softness 同时决定贴图分辨率与相机 far （越软只保留越贴近地面的那一段高度），动画模型再按 2× 放大阴影体积。
  • 属性面也已补齐：camera-orbit / camera-target / field-of-view（含 auto 与 min/max-field-of-view）、 getCameraOrbit() / getFieldOfView()、方向键转视角， 以及动画传输 availableAnimations / animationName / play() / pause() / paused / currentTime / timeScale、alt。 角度约定与 min/max-camera-orbit 一致（theta 从 +Z、phi 从 +Y）， 宿主的属性值可以直接在两边复用。
  • 本仓库多出的三件事（model-viewer 没有）：camera-name 切换到 glTF 内嵌相机、 setMorphInfluence() 手动驱动 morph target（动画正在写该通道时拒绝）、 camera-damping 拖拽惯性；另外离屏元素与后台标签页会暂停渲染。
  • 环境已同源：右侧 environment-image="neutral" 预设直接移植了 model-viewer EnvironmentScene('neutral') 的几何——同样的房间、6 个遮挡体、7 块发光板、 1 盏顶光，同样的 σ=0.04 预滤波。反射形状因此一致；整幅平均亮度仍有约 5% 差 （three r183 与 r186 的预滤波/色调映射实现差异，非数据差异）。
  • 取景已逐像素对齐：按 model-viewer updateFraming() 的算法复刻——距离取 顶点（而非包围盒角点）到目标中心的球半径，宽模型不改距离而是放宽垂直 FOV， 相机在 105% 半径处，正面 15° 仰角，无地面网格。实测 Fox / Helmet / Milk Truck / Water Bottle / Boom Box 的距离比均为 0.975–1.006。
  • 光照已对齐：tone-mapping 默认 neutral（即 model-viewer auto 在 glTF 上的解析结果），只由环境贴图照明。
  • 仍有差距：动画各自从加载完成起播，两栏的姿态会随时间漂移（取样问题，不是渲染差异）， 姿态不同则阴影形状自然不同；整幅平均亮度残留约 5%（见上条）。
